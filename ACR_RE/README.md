# Additional Campaign Rules. Rusbar Edition

`ACR_RE` объединит в одном современном моде настраиваемые правила кампании для культурных традиций, перемирий и заданий совета, а также согласованные общие изменения жизненных фокусов.

## Текущий этап

Версия `0.2.0` содержит интерфейс всех запланированных правил и полностью
реализованный культурный блок:

- дополнительные ячейки культурных традиций для всех существующих и вновь
  создаваемых культур;
- стоимость принятия культурных традиций для культур с главой-игроком;
- максимальный перерыв между культурными реформами для культур с
  главой-игроком;
- продолжительность перемирий;
- область действия изменённой продолжительности перемирий;
- максимальная продолжительность конечных заданий совета игроков.

Настройки перемирий и заданий совета пока остаются интерфейсными заготовками
для следующих этапов. Ванильные значения являются настройками по умолчанию.

Дополнительные ячейки выдаются скрытыми системными инновациями. Благодаря
этому они не занимают собственную ячейку традиции, не отображаются среди
обычных инноваций и не запускают кулдаун культурной реформы. Ванильные скидки
курултая сохраняются и применяются до выбранного игроком коэффициента.

Все новые скриптовые объекты используют префикс `ACR_RE_`.
