# Additional Campaign Rules. Rusbar Edition

`ACR_RE` объединит в одном современном моде настраиваемые правила кампании для культурных традиций, перемирий и заданий совета, а также согласованные общие изменения жизненных фокусов.

## Текущий этап

Версия `0.3.0` содержит интерфейс всех запланированных правил и полностью
реализованный культурный блок:

- дополнительные ячейки культурных традиций для всех существующих и вновь
  создаваемых культур;
- стоимость принятия культурных традиций для культур с главой-игроком;
- максимальный перерыв между культурными реформами для культур с
  главой-игроком;
- глобально ускоренное принятие новой традиции примерно до одного года;
- продолжительность перемирий;
- область действия изменённой продолжительности перемирий;
- максимальная продолжительность конечных заданий совета игроков.

Настройки продолжительности и области действия обычных послевоенных перемирий
реализованы. Настройки заданий совета пока остаются интерфейсной заготовкой для
следующего этапа. Стандартные значения являются настройками по умолчанию.

Дополнительные ячейки выдаются скрытыми системными инновациями. Благодаря
этому они не занимают собственную ячейку традиции, не отображаются среди
обычных инноваций и не запускают кулдаун культурной реформы. Стандартные скидки
курултая сохраняются и применяются до выбранного игроком коэффициента.

Скорость принятия традиции задаётся движковыми значениями и поэтому применяется
ко всем культурам, включая ИИ. На время тестирования установлен базовый
прогресс `50` в месяц: в зависимости от распространённости культуры новая
традиция принимается примерно за 2–12 месяцев, а замена существующей — за
3–16 месяцев. После тестирования рекомендуемое значение `8.34` вернёт
минимальную продолжительность примерно к одному году. Множитель замены `0.75`
и стандартное замедление `0.2` за каждое графство вынесены в тот же файл
defines для удобства ручной настройки.

Все новые скриптовые объекты используют префикс `ACR_RE_`.
