# Holding Manager (RUSBAR Edition)

## English

`Holding Manager (RUSBAR Edition)` is a fork of [Holding Manager Continued](https://steamcommunity.com/sharedfiles/filedetails/?id=3473706726), based on original mod version `1.16`.

- Fork version: `0.1.0`
- Supported Crusader Kings III version: `1.19.0.6`
- Fork author and maintainer: Ilya "RUSBAR" Barkalov

### Interface compatibility

The mod overrides the following interface files:

- `gui/window_county_view.gui`
- `gui/window_title.gui`

It may conflict with other mods that override the same files.

## Русский

`Holding Manager (RUSBAR Edition)` — форк мода [Holding Manager Continued](https://steamcommunity.com/sharedfiles/filedetails/?id=3473706726), основанный на версии оригинального мода `1.16`.

- Версия форка: `0.1.0`
- Поддерживаемая версия Crusader Kings III: `1.19.0.6`
- Автор и сопровождающий форка: Ilya "RUSBAR" Barkalov

### Совместимость интерфейса

Мод полностью заменяет следующие файлы интерфейса:

- `gui/window_county_view.gui`
- `gui/window_title.gui`

Он может конфликтовать с другими модами, заменяющими те же файлы.
