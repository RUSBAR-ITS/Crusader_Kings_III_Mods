# Holding Manager (RUSBAR Edition)

## English

`Holding Manager (RUSBAR Edition)` is a fork of [Holding Manager Continued](https://steamcommunity.com/sharedfiles/filedetails/?id=3473706726), based on original mod version `1.16`.

- Fork version: `0.1.0`
- Supported Crusader Kings III version: `1.19.0.6`
- Fork author and maintainer: Ilya "RUSBAR" Barkalov

### Interface compatibility

The mod overrides the following interface files:

- `gui/window_county_view.gui`
- `gui/window_title.gui`

It may conflict with other mods that override the same files.

An alternative vanilla county interface without the purple border is included as:

`ui option/window_county_view111.gui`

To use it:

1. Back up `gui/window_county_view.gui`.
2. Copy `ui option/window_county_view111.gui` into the `gui` directory.
3. Rename the copied file to `window_county_view.gui`, replacing the existing file.

### Совместимость интерфейса

Мод полностью заменяет следующие файлы интерфейса:

- `gui/window_county_view.gui`
- `gui/window_title.gui`

Он может конфликтовать с другими модами, заменяющими те же файлы.

Альтернативный ванильный интерфейс графства без фиолетовой рамки находится в файле:

`ui option/window_county_view111.gui`

Чтобы использовать его:

1. Создайте резервную копию `gui/window_county_view.gui`.
2. Скопируйте `ui option/window_county_view111.gui` в папку `gui`.
3. Переименуйте скопированный файл в `window_county_view.gui`, заменив существующий файл.
