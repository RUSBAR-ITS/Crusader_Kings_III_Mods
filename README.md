# Crusader_Kings_III_Mods
Mods for Crusader Kings III

## VS Code

Настройки рабочей области находятся в `.vscode` и применяются автоматически при
открытии корня репозитория в VS Code.

1. Установите рекомендованные расширения:
   - **CWTools — Paradox Language Services** для подсветки, автодополнения и
     диагностики CK3-скриптов;
   - **Paradox YML Highlight** для локализаций Paradox;
   - **DirectDraw Viewer** для просмотра DDS-текстур в редакторе.
2. Когда CWTools попросит указать папку игры, выберите корень установки
   `Crusader Kings III` с каталогами `game` и `binaries`.
3. Каждый мод храните в отдельной папке репозитория вместе с его
   `descriptor.mod`.

Для Paradox-скриптов включён язык CK3 и отступы табами. Файлы локализации `.yml`
сохраняются в UTF-8 с BOM, как требует игра. Миникарта включена, а вертикальные
ограничители и направляющие отключены.
