# More Talets Slots 60

Независимый мод для Crusader Kings III, увеличивающий максимальное число догматов создаваемой или реформируемой веры с 3 до 60.

## Как это работает

- Группа `doctrine_core_tenets` расширяется до 60 позиций.
- В окно создания веры временно добавляются 57 пустых догматов.
- Игрок заменяет любое число пустых позиций настоящими догматами.
- После создания веры служебное событие удаляет все оставшиеся пустые позиции.
- Окна просмотра и создания веры получают прокручиваемые сетки, рассчитанные на 60 позиций.

Оригинальный мод **More Tenets Slots** устанавливать одновременно не нужно: оба мода переопределяют одну и ту же группу догматов и те же GUI-файлы.

## Благодарности

Механика временных пустых догматов и исходная иконка основаны на работе Karax и Holger в модах [More Religion Tenets Slots](https://steamcommunity.com/sharedfiles/filedetails/?id=2218249327) и [More Tenets Slots](https://steamcommunity.com/sharedfiles/filedetails/?id=2904268802). RB_MTS60 представляет собой самостоятельную современную реализацию на 60 позиций с собственными именами объектов и воспроизводимой синхронизацией с актуальной игрой.

## Синхронизация после обновления игры

Запустите из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File tools/Sync-RBMTS60Tenets.ps1
```

Скрипт берет актуальную группу догматов и GUI из установленной версии CK3, сохраняет стандартную игровую логику и повторно применяет только изменения RB_MTS60. Путь к игре можно передать параметром `-GamePath`.

Для поддержки мода, который сам переопределяет группу `doctrine_core_tenets`, передайте его файл через `-DoctrineSourcePath`. Старые пустые позиции оригинального More Tenets Slots при этом отфильтровываются автоматически. Через `-GuiSourcePath` можно передать другой каталог GUI, если нужные блоки в нем сохраняют стандартную структуру CK3.

Сгенерированные файлы помечены предупреждением и не должны редактироваться вручную. Отчет о синхронизации создается в [docs/generated/RB_MTS60_SYNC_REPORT.md](docs/generated/RB_MTS60_SYNC_REPORT.md).

## Совместимость

Мод конфликтует с модификациями, которые переопределяют:

- `doctrine_core_tenets`;
- `gui/window_faith.gui`;
- `gui/window_faith_creation.gui`.

Такие моды требуют отдельной синхронизации или патча совместимости и соответствующего порядка загрузки.
