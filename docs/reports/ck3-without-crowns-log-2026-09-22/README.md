# Проверка запуска без Crowns of Westeros

Проверен запуск **22 сентября 2026 года, 14:41:01–14:42:13**. `error.log` завершён в 14:42:06. В `debug.log` подтверждена загрузка главного меню и штатный выход из него; загрузка сохранённой кампании и работа кнопок этим запуском не проверены. Игра агентом не запускалась.

Проверка только аналитическая: игровые исходники, Workshop, профиль, пресеты и порядок загрузки не изменялись. Сохранены [снимки журналов](snapshot), [27 активных модов](active-mods.json), [сводка](summary.json), [построчная классификация](diagnostics.csv) и [подтверждение запуска/выхода](debug-evidence.txt).

## Результат отключения

В списке запуска отсутствуют Crowns of Westeros, его Workshop-русификатор и локальное исправление перевода. AGOT+, AGOT_PLUS_FIX и Bookmarked также отсутствуют. Исправления переводов AGOT+ и Bookmarked теперь тоже выключены.

Все восемь исключённых файлов Crowns остаются вне игровых каталогов общего фикса. Действующий поставщик `events/activities/agot_coronation_activity/agot_coronation_crown_commission_events.txt` — основной **A Game of Thrones**. Архив Crowns не вернул его стартовую выдачу или расширенные события.

Упоминания корон в журнале сохранились по другой причине: **AGOT Submod Core содержит собственные интеграционные определения для Crowns и других необязательных модов**. Они продолжают проверяться без их оригиналов. Это не свидетельство повторной загрузки архивных файлов нашего фикса.

## Что появилось на поверхности после изменения состава

### Submod Core

640 сообщений об аксессуарах распределены по группам следующим образом:

- **560** — группы `asoiaf_*`, связанные с AGOT+;
- **48** — `crowns_of_westeros`;
- **28** — группы TGC;
- **4** — `brightboar_swordsman_armour`.

В этой категории 316 различных текстов сообщений; большинство повторяется, некоторые встречаются более двух раз. Поставщики групп и связанных портретных модификаторов проверены по активным исходникам.

В скриптовой категории Core даёт **282** сообщения о недоступных правилах: 141 первичную ошибку и 141 соответствующую запись `PostValidate`. Среди них 130 записей относятся к правилам Crowns, 80 — к настройкам одежды AGOT+, 56 — к `show_armor_enabled`, 16 — к TGC. Ещё одна запись — ранее известный `house_Blackfyre` из `tgc_loaded_trigger.txt`.

Оставшиеся 290 сообщений Core о переменных — 145 имён с двукратным повтором. Они относятся к интеграционным маркерам. Поиск упоминаний в эффективных TXT сохранён в [marker-references.json](marker-references.json); это поиск ссылок, а не доказательство достижимости каждой ветви.

В `gfx/portraits/accessories/COW_Headgear.txt:29` непосредственно найдено `maesteraemon_crown`, у которого написано `shared_pose_entity = hea` вместо используемого соседними определениями `head`. Этот файл поставляет **Core**, несмотря на имя `COW_Headgear`; он не относится к строительному COW-AGOT.

Ранее пользователь согласовал сохранение предусмотренных интеграций. Поэтому их массовое комментирование или восстановление отсутствующих модов по результатам этого запуска не выполнялось. Нельзя считать каждое сообщение доказанной поломкой основного AGOT; также одного отсутствия исходного сабмода недостаточно, чтобы гарантировать правильность всех оставшихся портретных условий.

### Legacy: недостающая адаптация Тёмной Сестры

Все **8** сообщений `Invalid artifact template 'vs_dark_sister_template'` происходят из двух ветвей одной функции `agot_create_artifact_vs_dark_sister_effect`. Действующий файл — [копия Legacy в нашем фиксе](../../../AGOT_Submods/AGOT_SUBMODS_FIX/common/scripted_effects/00_agot_artifact_vs_sword_effects_override.txt), строки 299 и 317. Номера в диагностике развёрнутой функции отличаются от номеров в файле на диске.

В общем фиксе были адаптированы шаблоны Чёрного Пламени, Морской Пены и топора Селтигаров, а эти две ссылки остались прежними. В отключённом [AGOT_PLUS_FIX](../../../AGOT_Submods/AGOT_PLUS_FIX/common/scripted_effects/asoiaf_scripted_effects_artifacts.txt) та же функция уже использует `valyrian_steel_template`. Теперь это исправленное переопределение не участвует в загрузке. Сам файл Legacy при исключении восьми файлов Crowns не менялся.

Безопасный кандидат на следующий шаг: заменить два устаревших шаблона на актуальный `valyrian_steel_template`, сохранив имя, визуальные варианты, свойства, историю и владельца меча. Это отдельная недостающая адаптация Legacy, а не основание возвращать Crowns или AGOT+.

## Собственные дополнения

В AGOT_DI_RUSBAR_ADDON найдены **36 предупреждений об отсутствии UTF-8 BOM в 32 файлах**. Движок прямо пишет, что всё равно попытается их прочитать. Можно добавить BOM, сохранив текст и LF; править только готовые файлы недостаточно, если соответствующий генератор впоследствии удалит BOM.

В AGOT_RB_HM **266 записей** о флагах — 133 идентификатора зданий с двукратным повтором. Генератор передаёт `special_slot` из GUI через `MakeScopeFlag(...GetCurrentOrConstrucingBuilding.GetKey...)`; затем триггеры сравнивают значение со `flag:<building_id>`. Обычного `set_flag` для таких значений не требуется. Код передачи находится в [build_runtime.py](../../../AGOT_Submods/AGOT_RB_HM/tools/build_runtime.py), около строки 484. По одному сообщению «используется, но не устанавливается» считать этот механизм сломанным нельзя.

Ошибок разбора GUI, неизвестных функций или условий, адресованных HM и Валирийскому Оку, в текущем `error.log` не найдено. Это подтверждение прохождения загрузки, не проверка отображения и нажатий: запуск завершён из главного меню.

## Прежние исключения и настройки

- **35 сообщений обычного DI**: ванильные семейства религий, персидская борьба, инновация, `e_hre`, `varangian`, `confucian_education_xp_gain_mult`. По прежнему указанию пользователя исходный DI для ванили не исправлялся.
- **FAB:** те же две ссылки `fab_aurion`, два сообщения о `fab_never_silent_sister`, 52 записи о сюжетных маркерах `fab_*` и шесть о значениях `hold`, `pact`, `shivers`. Всего прежние **62** записи, исследованные [20 сентября](../ck3-fire-and-blood-log-2026-09-20/README.md). Исправлять их ради очистки лога пользователь ранее не просил.
- В группе 74 записей об установленных, но якобы неиспользуемых значениях: 58 связаны с FAB, 8 — с интерфейсом DI, по 2 — с `dark_sister_artifact`, `COWAGOT_is_loaded`, `flag:all_found`, `global_seven_k_coa`. Последнее значение используется несколькими компонентами; сообщения не доказывают, что присваивания нужно удалять.
- **Два Ethiopian atlas** сохранены согласно прежнему решению пользователя.
- **Прочие четыре:** некорректный `supported_version` у Clear Notifications; отсутствующий/отрицательный `ai_check_interval` у `show_notifications_decision`; `buy_valyrian_mask.0001 is orphaned` у Legacy; `Achievements not loaded correctly`.

Составные ошибки правил соответствуют строкам 3, 8 и 13 в `player/game_rules/presets.txt`: «Набор Русбара», «AGOT Русбар», `LastAppliedRules`. Там действительно остались пустые значения и настройки отключённых AGOT+/Crowns. Файл читался без изменений. Это сохранённые пресеты, а не доказательство действующих правил загруженной кампании. Изменять их автоматически при задаче «проверить лог» не требовалось.

## Дополнительные журналы и вывод

В `gui_warnings.log` **483 записи**: после удаления временных меток они совпадают с сохранённым запуском 20 сентября. Новых GUI-предупреждений этой проверкой не обнаружено. `database_conflicts.log` содержит переопределения; сам факт переопределения не прибавляется к числу ошибок.

Проверка подтверждает отключение Crowns и отсутствие возврата его кода из общего фикса. Большой объём остатка создают интеграции Core и ограничения статического учёта флагов. Практически обоснованные следующие небольшие исправления — два шаблона Тёмной Сестры и кодировка собственных скриптов. Очистка необязательных интеграций Core и сохранённых пресетов требует отдельного решения о желаемом поведении; в этом аудите ничего из этого не менялось.
