# Адаптация исправлений MDE к русификатору 1.2

19 сентября 2026 года обновлён `AGOT_More_Dragon_Eggs_RUS_CORRECT` для More Dragon Eggs v56 и его внешнего русского перевода v1.2. Основание — [сверка Workshop](../more-dragon-eggs-workshop-update-2026-09-19/README.md). Основной MDE не обновлялся; его исходники совпали с прежними закреплёнными суммами.

## Разделение двух назначений Нагги

| Назначение | Ключ | Результат |
|---|---|---|
| Имя дракона в MDE | `MDE_nagga_desc` | `Nagga` / `Нагга`; существующее скриптовое обращение сохранено |
| Описание Холма Нагги в AGOT | `nagga_desc` | Оригинальные тексты AGOT и его русификатора сохраняются |

Прежний патч уже переименовал английское определение и ссылку в `common/customizable_localization/00_more_dragon_eggs_loc.txt`. Внешний русский перевод 1.2 заново добавил конфликтующее объявление `nagga_desc`. Теперь исходный относительный путь `localization/russian/mde_artifacts_l_russian.yml` перекрыт нашим файлом, в котором закомментировано только это объявление. Новое имя не дублируется здесь: оно уже существует в дополнительном русском файле патча.

В `localization/russian/dp_artifacts_l_russian.yml` закомментированы 140 одинаковых дублей: их действующие определения остаются в новом файле. Две уникальные строки о родителях (`mde_dragon_egg_gen_parent`, `mde_dragon_egg_gen_parents`) сохранены. Удалённых строк нет; снятие специальных комментариев побуквенно восстанавливает исходные тексты двух файлов.
