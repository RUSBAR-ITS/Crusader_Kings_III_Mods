# Объём изменений AGOT+ в исправлении ревизии 14

Сравнение с установленным оригиналом Workshop `2950245430` на 19.09.2026. Учитываются конечные игровые файлы **AGOT_PLUS_FIX**, а не сумма промежуточных правок. Исходники Workshop не менялись: сравниваются оригиналы и наши переопределения.

**Краткая оценка: изменено или отключено около 1,7% исходных строк без комментариев и пустых строк. Для игровых скриптов, историй и данных отдельно — около 2,1%. Если считать весь объём удаления/замены и вставки новых строк, получится около 5,4% от исходного текстового объёма.** Последняя величина — размер diff, а не доля переписанного оригинала: заменённая строка входит в него как удаление и как вставка.

## Исходные строки без комментариев и пустых строк

Локализация вынесена за пределы основного сравнения. Закомментированная ранее действовавшая строка считается удалённой из действующего текста. Комментарии и пустые строки удаляются для отдельного приблизительного подсчёта; это не семантический анализ механик. Перестановка строк, форматирование блоков и перенос одного выражения на несколько строк также могут влиять на diff.

| Область | Исходных строк | Удалено или заменено исходных строк | Доля |
|---|---:|---:|---:|
| Игровые скрипты, история и данные | 85 068 | 1 754 | 2,06% |
| DNA и внешности закладок | 82 355 | 2 202 | 2,67% |
| Текстовые определения графики и интерфейса | 81 657 | 312 | 0,38% |
| Метаданные DLC | 5 | 0 | 0% |
| **Итого без локализации** | **249 085** | **4 268** | **1,71%** |

В переопределённых файлах вставлено **8 670** строк действующего текста, включая замены; ещё **612** строк находятся в восьми новых файлах без локализации. Общий объём diff: `(4 268 + 8 670 + 612) / 249 085 = 5,44%`. Это не оценка доли изменившейся внешности или игрового поведения.

## Охват файлов и обычный построчный diff

- Оригинал содержит **530 текстовых файлов без локализации**, из них переопределены **77 — 14,53%**. Внутри большинства файлов изменена лишь часть строк.
- В области игровых скриптов, историй и данных затронуты **34 из 132 файлов — 25,76%**. При этом изменено около 2,06% исходных строк без комментариев и пустых строк: охват файлов значительно шире объёма изменений внутри них.
- В обычном diff, включая комментарии и пустые строки, без локализации заменены/удалены **4 371 из 271 242 строк — 1,61%**. Вставлены 11 547 строк в существующие файлы и 664 строки в новые; полный объём такого diff — 6,11% исходного объёма.
- Добавлены ещё четыре небольших файла локализации FIX — 38 строк. Отдельный мод `AGOT_PLUS_RUS_CORRECT` в расчёт не входит; для оценки исправления игрового кода он исключён.
- Одно дополнительное переопределение FIX основано на **AGOT**, а не на AGOT+: `common/on_action/agot_on_actions/agot_title_on_actions.txt`. Оно не подмешано в числитель изменений оригинала AGOT+.

## Бинарные ресурсы отдельно

Изменены **49 из 1 365 mesh-файлов AGOT+ — 3,59% моделей по количеству файлов**. Это исправления структуры данных, включая удаление лишних UV-свойств, а не полная переделка моделей. В этих файлах было 68 817 233 байта, стало 65 256 777; удалено 3 560 456 байт. Сохранность остальных данных проверена профильными тестами прежних пакетов.

Дополнительно через `replace_path` исключены **10 дублирующих моделей и четыре DDS**. Это отдельная операция исключения копий, а не изменение их геометрии или текстур. Их количество не прибавляется к 49 отредактированным моделям.

## Методика и воспроизведение

`Measure-Changes.py` проверяет SHA-256 исходников и конечных файлов по манифесту ревизии 14. Обычный diff использует `git diff --no-index --numstat --ignore-space-at-eol`: смена CRLF/LF и пробелы на концах строк не считаются исправлениями кода. Для приблизительного подсчёта действующих строк отдельно исключаются комментарии вне кавычек и пустые строки. Это подсчёт текста, включая структурные скобки и данные, а не AST-анализ.

Тесты, генераторы, отчёты, архивы, изображения и бинарные ресурсы не включаются в знаменатель строк кода. Сравниваются все оригинальные текстовые файлы, а не только выбранные для исправления. Поэтому процент не завышается за счёт исключения нетронутых частей мода.

```powershell
$env:PYTHONDONTWRITEBYTECODE='1'
python docs/reports/agot-plus-change-size-2026-09-19/Measure-Changes.py
```

Все числа: [summary.json](summary.json). Перечни исходников и изменений с хешами: [original-text-files.csv](original-text-files.csv), [changed-text-files.csv](changed-text-files.csv), [added-files.csv](added-files.csv). Скрипт пишет только эти отчётные файлы; мод и Workshop не изменяются.
