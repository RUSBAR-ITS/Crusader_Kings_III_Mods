## Новые предупреждения и выполненное исправление

В новом логе появились два предупреждения `lexer.cpp:306`: движок ожидает UTF-8 с BOM у файлов:

- `common/scripted_effects/zz_agot_plus_fix_child_effects.txt`;
- `common/modifiers/zz_agot_plus_fix_modifiers.txt`.

Движок сообщает, что всё равно попробует прочитать их. Это ошибка оформления новых файлов нашего пакета. При анализе она исправлена: в `docs/additions.json` включён BOM, патч пересобран. Проверено побайтово: в оба файла добавлены **только EF BB BF**, прежние байты содержимого не изменились; остальные 23 файла пакета сохранили хеши. Все статические проверки патча повторно прошли.

**В сохранённом логе эти два предупреждения остаются. Исправление кодировки сделано после проверенного запуска; его исчезновение в движке ещё не проверено.** Исторический снимок лога не редактировался. [Хеши и проверка изменений кодировки](encoding-fixes.json).

Ещё один формально новый текст — прежнее дублирование события `agot_activity_commission_crown.0001` между AGOT и Crowns of Westeros. В этот раз сообщение опять указывает на `agot_activity_events_crown_commission.txt`, вместо `agot_coronation_crown_commission_events.txt`. Та же смена пути уже разобрана в предыдущем отчёте. Одна старая запись заменена одной новой; отдельная новая проблема не появилась.
