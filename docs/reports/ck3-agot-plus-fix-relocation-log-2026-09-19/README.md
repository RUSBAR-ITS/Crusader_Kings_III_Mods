# AGOT+ после переезда на короткий путь: проверка запуска

Запуск 19.09.2026: начало **14:58:06**, выход из игры **15:01:08**, часовой пояс +07:00. Сравнение — с запуском ревизии 12 в 12:45 того же дня.

**Исчезли ровно 20 диагностик трёх файлов с прежними длинными путями: 18 ошибок деформаций женского доспеха Ланнистеров и два дубля геометрии королевских плащей. Остаток AGOT+ сократился с 135 до 115 сообщений. Новых диагностик AGOT+ нет.**

Это сильное подтверждение причины, найденной в исследовании длинных путей: исправления моделей уже существовали, после переезда движок перестал выдавать исходные ошибки. Порядок 32 модов сохранён, 139 исходников сборки совпадают с закреплёнными суммами, а все 84 файла FIX и восемь файлов исправления локализации совпадают с манифестами. От прежнего проверенного содержимого они отличаются только ранее согласованной нормализацией текстовых переносов строк. Двоичная исправленная модель сохранена побайтово. Изменение расположения подтверждено монтированием `D:/Repos/Crusader_Kings_III_Mods/AGOT_Submods/AGOT_PLUS_FIX` в `debug.log`.

## Почему общий лог стал больше

Число записей всего: **1848 → 1969**. Исчезли 20 диагностик AGOT+, добавилось 141 сообщение о дублирующихся ключах русификатора More Dragon Eggs:

- 140 совпадающих определений между `dp_artifacts_l_russian.yml` и новым `mde_artifacts_l_russian.yml`. Равенство значений обеих сторон проверено отдельно.
- Один конфликт `nagga_desc`: новый русский файл MDE использует ключ для имени «Нагга», а русификатор AGOT — для описания Холма Нагги.

Все 141 новые записи объяснены этим обновлением. Это отдельно от остатка AGOT+. Сверка содержимого и предложение по адаптации: [отчёт More Dragon Eggs](../more-dragon-eggs-workshop-update-2026-09-19/README.md).

Все проверенные цели прежних этапов 1–10 остаются отсутствующими. Не вернулись 130 предупреждений о переменных и ошибки по 386 исправленным ключам локализации. Два оставшихся сообщения DNA с `props_right` относятся к AGOT Bookmarked, не к AGOT+: [список](other-mod-dna.csv).

## Границы проверки и воспроизводимость

Проверены запуск, загрузка ресурсов и выход. Работа событий в партии и визуальная корректность портретов отдельно не тестировались. UV-файлы и остальные игровые ресурсы в этой проверке не изменялись.

Снимки текстов приведены к LF по политике репозитория; исходные и сохранённые SHA-256 записаны раздельно в [snapshot-summary.json](snapshot-summary.json). Это не побайтовая копия CRLF-логов, но их содержимое сохранено с точностью до переносов строк.

Результаты: [comparison-summary.json](comparison-summary.json). Повторная проверка сохранённого снимка при неизменных исходниках:

```powershell
python docs/reports/ck3-agot-plus-fix-relocation-log-2026-09-19/Verify-Run.py
```

`Capture-Snapshot.py` выполнялся один раз; повторная запись существующего снимка запрещена. Игровые файлы, Workshop, профиль и наборы модов при этом аудите не изменялись.
