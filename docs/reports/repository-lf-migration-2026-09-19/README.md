# Перевод текстовых файлов репозитория на LF

Текстовые файлы переведены на LF. Кодировки, BOM, текст игровых команд и локализаций сохранены. Файлы установленной игры, Workshop, профиля CK3 и игнорируемые каталоги сторонних модов не входят в миграцию.

## Что изменено

- В 1075 ранее отслеживаемых текстовых файлах CRLF и одиночные CR заменены на LF.
- `.gitattributes` задаёт `text=auto eol=lf`, исключает бинарные ресурсы из преобразований. Архивный UTF-16 LE файл нормализован с сохранением кодировки; Git обрабатывает его как бинарный, чтобы не менять отдельные байты UTF-16.
- `.editorconfig` закрепляет LF при редактировании, не переопределяя кодировку или BOM.
- Общий PowerShell-помощник `tools/RepositoryText.ps1` нормализует текст перед записью, сохраняя переданную кодировку. Обновлены использующие его генераторы, проверки локализаций и запись CSV.
- Python-запись через `Path.write_text` явно использует `newline='\n'`.
- Сборщик AGOT+ продолжает применять исходные точные рецепты к проверенным исходникам Workshop, затем нормализует готовый результат. Исходные контрольные суммы Workshop не пересчитывались.
- Контрольные суммы локальных результатов, утверждённых образцов, архивов и зависимых метаданных пересчитаны. Тесты сравнивают реконструированный текст в LF, затем по-прежнему строго проверяют байты, BOM и SHA-256 выходных файлов.

## Проверки

- В 411 игровых скриптах, файлах локализаций и описаниях ресурсов изменились только переводы строк. Дескрипторы модов также сохранены с точностью до переносов.
- Все 75 ранее отслеживаемых бинарных файлов сохранены побайтово.
- Полная сборка и все стадии `Test-AGOTPlusFix.ps1` проходят: 139 исходных контрольных сумм, 84 выходных файла, 1681 точечная замена.
- Повторная сборка побайтово воспроизводит 84 файла, манифест и внешний дескриптор.
- Проверены девять пакетов локализаций: AGOT, AGOT+, Bookmarked, Divine Intervention, More Dragon Eggs, COW AGOT, Crowns of Westeros, Legacy of the Dragon, Valyrian Steel.
- Проверены синтаксис PowerShell/Python, сохранение BOM, UTF-16, бинарных данных и байтов несовершенной кодировки исторического лога при нормализации.
- Все 1713 файлов во временном индексе Git побайтово совпадают с файлами на диске; результат записан в `validation.json`. Настоящий индекс и ветки не изменены; коммит и push не выполнялись.
- `git diff --check` отмечает 79 старых концевых пробелов в `docs/reports/agot-plus-dna-remaining-analysis-2026-09-19/definition-evidence.txt`. Они находятся в скопированном исходном коде и сохранены намеренно. Файл отличается от исходного экземпляра только нормализацией переносов; в остальных изменениях проверка проходит.

Игра при этой миграции не запускалась. Статические проверки подтверждают сохранение содержимого и воспроизводимость сборки, а не новый игровой прогон.

## Происхождение контрольных сумм

`original-file-hashes.json` содержит SHA-256 файлов на диске до миграции и SHA-256 после одной лишь нормализации. Список охватывает все 1704 файла, отслеживаемых в исходном коммите `c8ff52d`; исходные суммы относятся к рабочим копиям, где Git ранее использовал CRLF, а не к нормализованным Git-объектам. Это позволяет отличить изменение формата от последующих изменений генераторов и контрольных сумм.

`fingerprint-updates.json` перечисляет обновлённые ссылки на контрольные суммы локальных файлов. Суммы внешних исходников не заменяются суммами их нормализованных копий.

Исторические снимки текстовых файлов также переведены на LF. Их даты, сообщения игры и результаты прежних запусков сохранены. Старые утверждения о побайтовом совпадении со внешним источником описывают состояние на момент исходного захвата; после нормализации для сравнения исходных байтов служит `original-file-hashes.json`.

Резервная копия текстов до миграции находится локально в `.git/lf-migration-2026-09-19/original-text.zip`. Она не включается в коммит. Сценарий `migrate-fingerprints.py` документирует одноразовый пересчёт по этой копии и инвентаризации; он не является обычным этапом сборки.

## Обычная проверка формата

```powershell
python tools/Normalize-RepositoryText.py
& AGOT_Submods/AGOT_PLUS_FIX/tools/Build-AGOTPlusFix.ps1
& AGOT_Submods/AGOT_PLUS_FIX/tools/Test-AGOTPlusFix.ps1
```

Без `--write` нормализатор только проверяет файлы и возвращает ошибку при обнаружении CRLF/CR. Новые снимки внешних исходников могут требовать отдельной нормализации и обновления связанных контрольных сумм.
