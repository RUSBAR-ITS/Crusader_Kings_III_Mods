## Почему могли не сработать три исправления моделей

Файлы совпадают с согласованными результатами по SHA256 и записаны до запуска; монтирование папки FIX подтверждено. Проверка порядка модов на файловой системе не обнаружила более поздних копий по этим относительным путям. Однако это **не подтверждает чтение каждого ресурса движком**.

| Исправленный ресурс | Длина полного локального пути | Результат лога |
|---|---:|---|
| `asoiaf_ironborn_legs_coa.asset` | 246 | Диагностика исчезла |
| Мужской королевский плащ Ланнистеров `.asset` | 278 | Дубль модели остался |
| Женский королевский плащ Ланнистеров `.asset` | 282 | Дубль модели остался |
| Женский доспех Ланнистеров `.mesh` | 283 | Все 18 сообщений остались |

Есть точное совпадение между не подтвердившимися исправлениями и путями длиннее 260 символов. **Рабочая гипотеза — ограничение длинных путей при загрузке этих ресурсов.** Это ещё не установленная причина: текущий лог не показывает, какой физический файл каждой модели прочитан. Для проверки нужен отдельный запуск с коротким путём к тому же содержимому патча. Такой эксперимент в этом аудите не выполнялся. [Пути, длины и хеши](resource-path-investigation.json).
