## Правило небольшой поправки

Для четырёх старых настроек с диапазоном −1…1 используется консервативная эвристика:

```text
delta = clamp(round((2 × old_value − 255) / 4), −16, +16)
```

Это четверть условного отклонения от середины старой шкалы, с дополнительным ограничением. Значения 127 и 128 дают нулевую поправку. Максимальное изменение современной условной силы — 16 пунктов шкалы 0…255. **Коэффициент 1/4 и предел 16 выбраны для этого приближения; они не взяты из документации движка и не являются доказанной формулой миграции.** Числовой предел также не означает, что визуальное различие всегда составляет определённый процент.

Правила направления:

- Размер глаза → `gene_bs_eye_size`. Шаблоны `eye_size_neg/pos` в текущем AGOT имеют явные ссылки друг на друга как зеркальные варианты. Их условные силы рассматриваются со знаком, поправка прибавляется к имеющейся настройке. Переход через ноль допускается.
- Верхнее веко → `gene_bs_eye_upper_lid_size`. По названиям увеличение старого `shut_top` условно сопоставляется с увеличением размера верхнего века. Это смысловое предположение, не доказанная геометрическая эквивалентность. У ненулевой существующей настройки сохраняется её ветвь: если поправка пересекла бы ноль, значение останавливается на нуле. AGOT отключил зеркальные ссылки у этих шаблонов, поэтому они не считаются точными противоположностями.
- Внутренняя ширина бровей → `gene_eyebrow_inner_width`. Аналогия по назначению с небольшой поправкой. Старое сочетание движения костей и двух деформаций не воспроизводится. Уже заданная ненулевая ветвь также не меняется на противоположную.
- Нижнее веко → `gene_bs_eye_lower_lid_size`. У всех 53 затронутых пресетов соответствующие современные аллели сейчас `vanilla_eye_lower_lid_size 0`. Доступен положительный `eye_lower_lid_size`; слабое положительное воздействие переносится в него. Для отрицательного направления аналога в этом гене нет — оно остаётся нейтральным. Никакой старой анимации для него не подключается.

Оба аллеля обрабатываются независимо. Диапазон результата ограничен 0…255. Если поправка округлилась в ноль или уже упёрлась в предел, современная запись сохраняется без изменения.

Пример `Slynt_asoiaf_1`:

| Современная настройка | До | После | Основание |
|---|---|---|---|
| Размер глаза | `eye_size_pos 0` | `eye_size_neg 3` | Слабое уменьшение по старому значению 122 |
| Верхнее веко | `eye_upper_lid_size_neg 43` | `eye_upper_lid_size_neg 37` | Небольшая поправка, исходная ветвь сохранена |
| Нижнее веко | Пустой шаблон, 0 | Без изменения | Старое отрицательное направление не переносится |
| Ширина бровей | `eyebrow_inner_width_max 11` | `eyebrow_inner_width_max 13` | Поправка +2 |
| Основная складка | `eye_fold_shape_pos 27` | Без изменения | Уже заданная форма важнее старой дополнительной |

У этого пресета оба аллеля совпадают; в CSV записаны оба, а не только видимая составляющая.

## Складка: три переноса, 62 сохранения основной формы

Здесь есть более сильное соответствие: текущий шаблон `eye_fold_shape_neg_02` воздействует на тот же атрибут `bs_eye_fold_2`, что историческая дополнительная складка. Но это вариант уже занятого гена основной складки, а не второе независимое поле.

Переносить старое значение предлагается только когда сила соответствующего современного аллеля равна нулю. У найденных пресетов это ровно три случая, по два аллеля каждый:

| Пресет | Современная запись после переноса |
|---|---|
| `Dayne_asoiaf_4` | `eye_fold_shape_neg_02 2 / 2` |
| `Eunuch_asoiaf_1` | `eye_fold_shape_neg_02 81 / 81` |
| `Payne_asoiaf_6` | `eye_fold_shape_neg_02 15 / 15` |

Байт силы сохраняется; действуют нынешние диапазоны AGOT: максимум 0,95 у взрослых и 0,5 у детей. Подгонять их к историческому максимуму 1,0 не предлагается: выбран приоритет текущей реализации AGOT. Лимит ±16 относится к эвристическим поправкам четырёх других генов; здесь используется существующий атрибут в свободном поле и исходная сила.

В остальных 62 пресетах не меняется ни один аллель современной основной складки. Старое дополнительное воздействие будет убрано из исполняемой DNA. Это осознанная потеря отдельной детали в пользу сохранения уже работающей формы и неизменной общей схемы.

- все 250 исходных диагностик имеют предусмотренное исправление в пробных файлах;

- в затронутых пресетах не остаётся пяти старых неизвестных генов и повторных полей;

- данные вне блока genes, включая ссылки на историю, entity и tags, сохранены;

Статическое покрытие 250 сообщений не равно результату нового игрового запуска. Оно показывает, что их причины в этих записях устранены по текущей схеме. Остальные категории ошибок из лога этим планом не охватываются.
