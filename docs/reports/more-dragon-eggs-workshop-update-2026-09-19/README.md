# Сверка обновления русификатора More Dragon Eggs

**Обновился внешний русификатор `3736931686`: версия 1.1 → 1.2. Основной More Dragon Eggs версии 56 и остальные закреплённые источники не изменились. Обновление улучшило покрытие переводом, но добавило дубли и вновь создало русский конфликт `nagga_desc`.**

Это анализ. Игровые файлы, сборщик и базовые контрольные суммы не изменялись. Зафиксированы установленная версия 1.2 и её исходные SHA-256; старые тексты сопоставлялись с сохранённым каталогом записей версии 1.1. Старые комментарии и исходные переносы строк каталог не содержит, поэтому сравнение этих деталей не заявляется.

Часть записей перенесена между файлами. Например, прежний `dp_domicile_buildings_l_russian.yml` теперь содержит только заголовок, а четыре определения зданий находятся в новом `mde_domicile_buildings_l_russian.yml`. Само опустошение старого файла не означает потерю перевода.

Наша установленная коррекция сохраняет все 18 выходных файлов с ожидаемыми SHA-256. Все 27 изменённых прежних ключей уже имеют собственные определения в нашем патче; среди них подсказки драконьих ям, настройки вылупления и несколько описаний событий. Из 331 нового ключа 330 уже покрыты нашим патчем. Оставшийся `nagga_desc` намеренно не должен использоваться для имени дракона: для него у нас есть `MDE_nagga_desc`.

Файлы и суммы: [upstream-file-changes.csv](upstream-file-changes.csv). Все изменения ключей: [key-changes.csv](key-changes.csv). Тексты 27 изменённых записей рядом с нашей редакцией: [changed-existing-translations.csv](changed-existing-translations.csv).

## Новые сообщения лога

| Причина | Сообщений | Смысл |
|---|---:|---|
| Описания яиц одновременно в `dp_artifacts_l_russian.yml` и `mde_artifacts_l_russian.yml` | 140 | Значения обеих сторон побуквенно одинаковы; по этим парам смыслового расхождения нет |
| `nagga_desc` в новом файле MDE и русификаторе AGOT | 1 | Разные назначения одного ключа: имя дракона и описание достопримечательности |
| **Всего новых записей** | **141** | Полностью соответствует разнице свежего и прежнего логов |

В новой версии MDE `nagga_desc` равен «Нагга». В AGOT он содержит описание останков морского дракона на холме. Наш прежний патч уже переименовал английское определение и скриптовое обращение в `MDE_nagga_desc`, но нового русского объявления тогда не существовало. Его необходимо обработать при адаптации, иначе общий ключ снова имеет две разные трактовки. Порядок выбора значения движком отдельно не проверялся.

Доказательства: [140 одинаковых пар](new-log-duplicate-pairs.csv), [конфликт Нагги](nagga-conflict.json). Это не новые ошибки AGOT+.

## Предлагаемая адаптация

1. Закрепить текущие 10 изменённых сумм и два новых файла: список входных файлов станет 161 вместо 159. Обновить версию русификатора и проверки состава каталога (1045 вместо 895 ключей).
2. Сохранить согласованную редактуру нашего патча. Простое обновление сумм недостаточно: сборщик сейчас выбирает часть резервных переводов по их отсутствию во внешнем русификаторе, а версия 1.2 добавила эти ключи. Такая смена входных данных может убрать прежние исправления без отдельного решения.
3. Перекрыть старый `localization/russian/dp_artifacts_l_russian.yml`, закомментировав только 140 одинаковых дублей. Обязательно сохранить две уникальные записи: `mde_dragon_egg_gen_parent` и `mde_dragon_egg_gen_parents`.
4. Перекрыть новый `localization/russian/mde_artifacts_l_russian.yml`, закомментировав только конфликтующее объявление `nagga_desc`. Имя дракона продолжит брать существующее определение `MDE_nagga_desc` из нашего патча; описание Холма Нагги останется у AGOT.
5. Расширить проверку Нагги на новый русский исходник и повторить существующие проверки 1047 ключей, подстановок, форматирования и неизменности GUI/скриптов. После применения следующий запуск должен отдельно подтвердить исчезновение 141 сообщения.

Геймплей, вероятности, английские исходники и Workshop для такой адаптации менять не требуется. Предложенные перекрытия здесь ещё не установлены.
