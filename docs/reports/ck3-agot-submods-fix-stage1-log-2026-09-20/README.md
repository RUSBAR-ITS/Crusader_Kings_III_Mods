**Все 103 запланированных сообщения исчезли.** Сохранены ровно **143 согласованных исключения и 18 отложенных сообщений**. Возврата проверявшихся ошибок предыдущих этапов AGOT+ и More Dragon Eggs не обнаружено.

Запуск: **01:56:46–02:01:07, UTC+7**. Игра завершилась штатно. `debug.log` подтверждает подключение `D:/Repos/Crusader_Kings_III_Mods/AGOT_Submods/AGOT_SUBMODS_FIX`. Запись о монтировании и отсутствие ошибок не доказывают выполнение каждой цепочки событий: запуск проверяет загрузку, выполнение событий в кампании и визуал отдельно не проверялись.

## Одно новое предупреждение и внесённая правка

Игра сообщила:

```text
File 'common/scripted_effects/usf_language_effects.txt' should be in utf8-bom encoding (will try to use it anyways)
```

Это собственный новый файл единого патча. После сохранения снимка ему добавлен **только UTF-8 BOM: `EF BB BF`**. Размер изменился с 577 до 580 байт; декодированный текст скрипта побайтово эквивалентен прежнему. Другие **25 игровых файлов не изменились**. Обновлены сборщик, контрольная сумма и проверка BOM; сборщик теперь сохраняет время изменения файлов, чьи байты уже совпадают с результатом сборки.

Все **146 статических проверок прошли**. **Исчезновение предупреждения в игре ещё не проверено**: это изменение сделано после исследуемого запуска. Сам свежий лог не редактировался. Доказательство объёма изменения и суммы до/после: [post-launch-bom-fix.json](post-launch-bom-fix.json).

## Методика и воспроизводимость

Снимок сохраняет исходные и нормализованные SHA-256, даты, дескрипторы и версии манифестов. LF используется только в копиях для отчёта. Для сравнения нормализованы номера строк и `args#`, сохранены пути, тексты, компоненты и кратность сообщений.

Прямое сравнение даёт 105 пропавших и три добавленных сообщения. Два из каждой группы — старые ошибки COW `rhoynish_religion_opinion`: в новой записи добавлена конструкция `expanded from file`. Эти два случая сопоставлены отдельно только для данного токена, компонента и полного пути, без глобального игнорирования различий. В результате подтверждены **103 исчезновения и одно новое предупреждение**. [Проверенные различия формы сообщений](reviewed-diagnostic-variations.csv).
