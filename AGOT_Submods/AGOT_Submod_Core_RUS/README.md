# AGOT Submod Core | Русификатор

Русская локализация **AGOT Submod Core 1.5.5** (Workshop `3034473189`) для CK3 **1.19.x**. Проверена установленная версия на 18.09.2026. Версия русификатора: **1.0.0**.

Submod Core объединяет общие ресурсы и файлы совместимости для сабмодов AGOT. В проверенной версии у него один собственный английский файл локализации, `localization/english/smc_barbershop_l_english.yml`, и **четыре строки** с названиями платьев в редакторе внешности. Все четыре переведены:

| Английский текст | Русский текст |
|---|---|
| Hightower Pious Dress | Платье благочестивой дворянки (Хайтауэры) |
| Reachman Pious Dress | Платье благочестивой дворянки (Простор) |
| Alicent's Pious Dress | Платье благочестивой дворянки (Алисента) |
| Hightower Pious Dress - No Chain | Платье благочестивой дворянки (Хайтауэры, без цепочки) |

Иконка `@asoiaf_icon!` сохранена во всех четырёх строках.

## Терминология

Имена и названия проверены по русской энциклопедии 7kingdoms: [Алисента Хайтауэр](https://7kingdoms.ru/wiki/Алисента_Хайтауэр), [Хайтауэры](https://7kingdoms.ru/wiki/Хайтауэры), [Простор](https://7kingdoms.ru/wiki/Простор).

Формулировка «Платье благочестивой дворянки» согласована с русификатором основного AGOT: ключ `PORTRAIT_MODIFIER_custom_clothes_pious_dress_04` в `localization/russian/agot/portraits/agot_portrait_modifiers_l_russian.yml:1221`. Сами названия моделей одежды сформулированы для интерфейса мода; энциклопедия подтверждает содержащиеся в них имена и географические названия.

## Подключение

1. Скопировать соседний [AGOT_SUBMOD_CORE_RUS.mod](../AGOT_SUBMOD_CORE_RUS.mod) в `C:/Users/RUSBAR/Documents/Paradox Interactive/Crusader Kings III/mod/`.
2. Добавить **AGOT Submod Core | Русификатор** в игровой набор лаунчера и расположить ниже **AGOT Submod Core**.
3. Запустить игру на русском языке. Если игра уже открыта, потребуется перезапуск.

Файл `.mod` указывает на папку русификатора в этом репозитории. При переносе папки нужно обновить его `path`. Порядок остальных сабмодов определяется их требованиями; этот русификатор добавляет только четыре русских строки. Русификатор основного AGOT и `AGOT_RUS_CORRECT` используются отдельно.

**18.09.2026 мод зарегистрирован и включён в набор `AGOT-RUSBAR`** после Submod Core. Игра читает его файлы непосредственно из этого репозитория. [Состояние подключения и резервная копия](../../docs/context/INSTALLED_AGOT_LOCALIZATIONS_2026-09-18.md).

## Объём проверки

Файл [smc_barbershop_l_russian.yml](localization/russian/smc_barbershop_l_russian.yml) покрывает все четыре ключа английской локализации Submod Core 1.5.5. Проверены совпадение ключей, отсутствие дублей, сохранение иконок, кавычки, заголовок `l_russian` и кодировка UTF-8 с BOM.

Также проверены явные ссылки на локализацию в `common` и `gui`: подсказки `agot_is_independent_crown_tooltip_desc` и `must_be_crowned_tooltip_desc` уже переведены русификатором AGOT. `trait_hidden` и `trait_hidden_desc` имеют намеренно пустые значения для скрытых признаков.

Вариант платья `_03` без цепочки пока отключён автором в `common/genes/05_genes_special_accessories_clothes.txt:5103` с пометкой об отсутствующей модели. Перевод для существующего ключа добавлен; доступность модели определяется Submod Core.

Русификатор не содержит копий `common`, `gfx`, `gui` или файлов английской локализации. Отображение в запущенной игре пока не проверялось.
