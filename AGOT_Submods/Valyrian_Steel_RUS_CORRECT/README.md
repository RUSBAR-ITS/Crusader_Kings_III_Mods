# Valyrian Steel | Исправления русификатора

Корректирующий мод для **Valyrian Steel 1.4.1** (`2962713441`) и **Valyrian Steel - Русификация 1.4.1-ru** (`3736917258`), подготовленный по [сверке от 18 сентября 2026](../../docs/reports/valyrian-steel-russian-2026-09-18/README.md).

## Изменения

Исправлены семь подтверждённых проблем из отчёта:

- В воспоминании о финансировании собственной экспедиции имя исследователя берётся из `owner`, а не отсутствующего `adventurer`.
- Воспоминание о ранении в Валирии использует своё описание от третьего лица. Чужое ванильное описание не переопределяется.
- В четырёх строках для правительницы выбираются формы «готова», «велела», «ждала». Для правителя сохранены формы мужского рода.
- Из общей подписи бонусов рога, плети и книги убрано уточнение «с помощью драконьего рога».

Также закрыта пропущенная кавычка в английской строке `fund_expedition_0012_desc`, отмеченная в отчёте как техническая ошибка оригинала.

Редакторские замечания не включены: падежи имён, направление плавания, описания драконов, яиц и свечей сохранены. В исправляемом воспоминании заменён только недоступный участник; остальное предложение не переписано.

## Подключение

В лаунчере мод называется **Valyrian Steel | Исправления русификатора**. Размещать после **Valyrian Steel - Русификация**, который должен идти после **Valyrian Steel**. Оба исходных мода нужны.

Внешний дескриптор [VALYRIAN_STEEL_RUS_CORRECT.mod](../VALYRIAN_STEEL_RUS_CORRECT.mod) указывает прямо на эту папку репозитория. Для подключения достаточно его копии в `Документы/Paradox Interactive/Crusader Kings III/mod/`. Выбор игрового набора выполняется пользователем в лаунчере.

## Состав и проверка

- `localization/replace/russian/zzzz_valyrian_steel_rus_correct_l_russian.yml` — шесть исправленных русских ключей.
- `common/character_memory_types/valyrian_memories.txt` — полная копия исходного файла с единственной заменой ссылки описания. Все восемь типов воспоминаний, их длительность и участники сохранены.
- `localization/english/valyrian_decisions_l_english.yml` — полная копия с единственной добавленной закрывающей кавычкой.

Копии лежат по тем же относительным путям, чтобы заменить конкретные исходные файлы без дублирования определений. `replace_path` не используется. Числа, награды, цены, вероятности и события не изменены.

[corrections.json](docs/corrections.json) задаёт точные замены. [source-baseline.json](docs/source-baseline.json) фиксирует SHA-256 18 проверенных EN/RU-файлов и исходного скрипта воспоминаний. [source-manifest.json](docs/source-manifest.json) содержит изменения и хеши готового мода.

Из корня репозитория:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File AGOT_Submods/VALYRIAN_STEEL_RUS_CORRECT/tools/Build-ValyrianSteelRusCorrect.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File AGOT_Submods/VALYRIAN_STEEL_RUS_CORRECT/tools/Build-ValyrianSteelRusCorrect.ps1 -Check
```

Проверяется покрытие всех 286 ключей, формат локализации, доступность участников всех восьми воспоминаний, обе формы рода в четырёх исправленных строках и отсутствие изменений вне заданных фрагментов. Режим `-Check` ничего не записывает и сравнивает готовые файлы побайтово с ожидаемым результатом. Проверка не заменяет просмотр в запущенной игре.

При изменении любого исходного файла сборка и проверка останавливаются: после обновлений нужна повторная сверка, поскольку полные копии могут скрывать новые изменения оригинала.
