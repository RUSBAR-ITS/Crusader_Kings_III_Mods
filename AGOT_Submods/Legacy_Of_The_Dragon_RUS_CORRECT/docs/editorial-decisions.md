# Обоснование правок

Изменения подготовлены 18 сентября 2026 по установленным файлам Legacy и его перевода. Исходный аудит сохранён отдельно; исправления не записываются в Workshop.

| Пункты аудита | Решение |
|---|---|
| LOTD-001, LOTD-002 | Исправлены две ссылки внутри `read_prophecy_to_heir`. Общие ключи обычного чтения не переопределяются. В трёх русских описаниях передачи имя наследника перенесено в позицию подлежащего. |
| LOTD-003 | Условие результата в сценарии сохранено; выбранные этим условием описания и позы приведены в соответствие с `blackfyre` / `blackfyre_rehilt`. Изменение отображения не меняет саму переделку, цену и награды. |
| LOTD-004, LOTD-005 | Добавлены алиасы старых ключей в EN и RU. Тексты берутся из актуальной локализации AGOT, без копирования его большого сценария редактора дома. |
| LOTD-006 | Перечислены шесть дат из `is_shown` решения. Различены доступность поиска и начальный набор реликвий; не обещается работа на произвольном более позднем старте. |
| LOTD-007 | Убрано утверждение об убийстве Эйниса Мейгором. Дополнительно перестроены две фразы с именами Эйниса и Джейхейриса, которым раньше требовался родительный падеж. |
| LOTD-008 | Форма определяется по `ancestor_1.IsFemale`; существующие формы по полу ROOT в той же строке сохранены. |
| Редакторские: падежи | В шести отмеченных строках имя используется как подлежащее, а не как прямое/косвенное дополнение, требующее другого падежа. Существующие scopes и ссылки на персонажей сохранены. |
| Редакторские: топор | Подсказка связывает прежнее имя «Клешня Краба» с названием «Бедствие», которое используется для модели Legacy. Названия самого предмета и поз остаются согласованными. |
| Редакторские: маска | Текст соответствует двум веткам `viserys_mask_template`: здоровье проверяется при личном ношении, но не при выставлении на пьедестале. |
| Редакторские: сабля | «Полуторная сабля» передаёт исходное `hand-and-a-half sabre`. |
| Варианты для Эйгона | В двух событиях добавлен `triggered_desc` для `root = character:Targaryen_27`, затем обычный вариант. Использованы существующие тексты EN/RU; новые сцены не сочинялись. |
| Уже исправленное в RU | Английские RGB-компонент и неиспользуемая заглушка приведены в порядок; русские строки по этим двум поводам не дублируются. |

Историческая поправка об Эйнисе основана на установленной истории AGOT (`Targaryen_30`, причина смерти `death_heart_attack`) и [статье 7kingdoms об Эйнисе I](https://7kingdoms.ru/wiki/Эйнис_I_Таргариен), прочитанной при аудите. Причина смерти сформулирована нейтрально: версия об отравлении не представляется установленным фактом. Полная проверка всей авторской истории предметов по книжному канону не выполнялась.

Предупреждения о внутренних прямых кавычках EN, сторонних ванильных заголовках и валирийских глифах не являются подтверждёнными ошибками из этого аудита. Глифы, ссылки на шрифт и содержательные английские цитаты в них сохраняются.
