# AGOT DI — Валирийские дары RUSBAR

Дополнение к Divine Intervention для AGOT. Версия 0.1.0 рассчитана на CK3 1.19.0.6 и исследованные определения AGOT 0.5.2.1. Все действия доступны игроку в категории DI при включённом меню читов.

## Возможности

| Взаимодействие | Действие |
|---|---|
| Совершенствовать образование | Поднимает уже имеющиеся направления образования до максимальной ступени. |
| Обрести валирийское мастерство | Повышает шесть базовых навыков на 10/20/30/40/50 либо до предела игры. |
| Вернуть юность | Омолаживает живого человека старше 16 лет до 16 лет. |
| Испить крови Древней Валирии | Коррекция наследственных недостатков либо коррекция с выдачей благоприятных свойств. |
| Испить крови Праматери Драконов | Аналогичная процедура для драконов; долговязость сохраняется. |
| Обратиться к Валирийским Богам | Выдаёт или снимает одно из трёх согласованных благословений/состояний. |
| Валирийское Око | Создаёт верного простолюдина при дворе получателя и назначает на выбранную свободную должность. |
| Изучить Древние Валирийские трактаты | Готовит существующего персонажа для первой поддерживаемой занимаемой должности. |

«Око» содержит семь вкладок. Предусмотрены 93 профиля создания; конкретный список зависит от получателя, построек, правительства, веры, культуры, DLC и вакансий. Настройки по умолчанию: культура и вера получателя, возраст 16 лет, случайный пол. Возраст выбирается в пределах 16–80 лет. Обязательные требования должности имеют приоритет и указаны в её подсказке.

Культуры и веры берутся из полных игровых списков при открытии окна, включая созданные в кампании. В этой версии фильтр ищет **точное полное название с учётом регистра**; поиск по части слова не реализован. Пустое поле показывает все варианты.

«Трактаты» поддерживают 120 профилей. Если должностей несколько, используется первая по идентификатору в алфавитном порядке. Не меняют работодателя и не переназначают персонажа. Верность не добавляют; повышенные базовые навыки сохраняют. Исключение — Прислуга: её навыки обнуляются и добавляется «Валирийский раб».

## Подключение

Расположить после **A Game of Thrones**, **Divine Intervention Cheat Menu** и **Divine Intervention AGOT Cheat Menu**, а также после модов, изменяющих придворные должности. Русские и английские строки входят в дополнение. Старый DICM_RBE не требуется.

Файл регистрации: [AGOT_DI_RUSBAR_ADDON.mod](../AGOT_DI_RUSBAR_ADDON.mod). Он указывает на папку в этом репозитории; копия размещена в `Documents/Paradox Interactive/Crusader Kings III/mod/AGOT_DI_RUSBAR_ADDON.mod`. Набор и порядок в лаунчере выбираются вручную.

Исходники Workshop не изменяются; файлы DI/AGOT не перекрываются. Для работы создаваемых специалистов используются штатные назначения и их обычные последствия, включая зарплату и требования должности.

## Проверка

```powershell
python -X utf8 -m unittest discover -s AGOT_Submods/AGOT_DI_RUSBAR_ADDON/tests -v
```

Это статические проверки и модель исполнения эффектов, а не запуск CK3. Подробности и сценарии первого игрового запуска: [отчёт реализации](docs/implementation-2026-09-20.md).
