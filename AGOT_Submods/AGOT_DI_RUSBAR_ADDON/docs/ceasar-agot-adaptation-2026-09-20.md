## Добавленные множители опыта

Все восемь параметров получили значение `999`, соответствующее принятому в исходном «Цезаре» усилению опыта. Использован один общий множитель для каждого свойства, без дополнительного усиления отдельных шкал того же свойства.

| Свойство | Параметр | Охватываемые шкалы |
|---|---|---|
| Драконий всадник | `dragonrider_xp_gain_mult` | `dragon_training`, `dragon_bond` — обучение и связь с драконом |
| Оруженосец / рыцарь | `squire_xp_gain_mult` | `knight` |
| Мейстер | `maester_xp_gain_mult` | `maester` |
| Служба в Ночном Дозоре | `nightswatch_xp_gain_mult` | `nightswatch` |
| Строитель Ночного Дозора | `lifestyle_nw_builder_xp_gain_mult` | `lifestyle_nw_builder` |
| Разведчик Ночного Дозора | `lifestyle_nw_ranger_xp_gain_mult` | `lifestyle_nw_ranger` |
| Стюард Ночного Дозора | `lifestyle_nw_steward_xp_gain_mult` | `lifestyle_nw_steward` |
| Мореход | `lifestyle_mariner_xp_gain_mult` | `lifestyle_mariner` |

Восемь свойств содержат девять шкал опыта. В стандартной формуле множитель `999` означает прибавку 99 900%, то есть номинально ×1000 без других модификаторов; предел самой шкалы сохраняется. Это не добавление свойства и не начисление опыта само по себе: нужен соответствующий источник опыта. Множитель также не заменяет отдельные события посвящения, условия, флаги и прямые установки уровня.

«Социальная фигура» (`esr_social_standing`) исключена целиком: множители не добавлены ни для свойства, ни для его четырёх шкал. Ожоги (`burned`) также не включены: повышение их уровня усиливает последствия травмы. Наследственные свойства без шкалы опыта не получают вымышленных XP-параметров.

## Удалённые параметры

| Параметры | Основание |
|---|---|
| `confucian_education_xp_gain_mult` | Свойство `confucian_education` отсутствует в действующем каталоге свойств установленной сборки. |
| `charioteer_blue_xp_gain_mult`, `charioteer_green_xp_gain_mult`, `charioteer_white_xp_gain_mult`, `charioteer_red_xp_gain_mult` | Свойства существуют, но обычная разблокировка гонок колесниц отключена AGOT. Это исключение неприменимой механики, а не исправление отсутствующих идентификаторов. |

Турнирные параметры и `knight_errant_xp_gain_mult` сохранены: соответствующие механики представлены в действующем коде AGOT. Параметры лагеря, ресурсов, строительства и происков не удалялись только из-за их происхождения из основной игры.

`movement_speed` и `naval_movement_speed_mult` оставлены как военные бонусы. Параметры скорости путешествий персонажа в эту адаптацию не добавлялись.
