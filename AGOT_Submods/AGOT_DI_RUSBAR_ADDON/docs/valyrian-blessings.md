# Валирийские благословения

Подготовлены 20 сентября 2026 года. Определения находятся в [common/modifiers/agot_di_rusbar_blessings.txt](../common/modifiers/agot_di_rusbar_blessings.txt).

| Название | Идентификатор | Источник параметров | Исходник иконки |
|---|---|---|---|
| Большое Валирийское Благословение | `agot_di_rusbar_great_valyrian_blessing` | `DICM_RBE_Ceasar` из подготовленного файла `temp/DICM_RBE_modifiers.txt` | `assets/Valyrian_Bless_High.png` |
| Валирийское Благословение | `agot_di_rusbar_valyrian_blessing` | `DICM_RBE_Ceasar_Wife` из того же файла | `assets/Valyrian_Bless.png` |
| Валирийский раб | `agot_di_rusbar_valyrian_slave` | `DICM_RBE_Ideal_Stooge` из того же файла | `assets/Valyrian_Slave.png` |

Названия используют нормативное написание «благословение». Числовые параметры перенесены из текущего пользовательского файла, включая изменения после первоначального исследования. При переносе изменены только идентификаторы и ссылки на иконки. Исходные блоки в `temp` сохранены.

Большое благословение содержит 170 игровых параметров, в том числе [восемь добавленных множителей опыта AGOT](ceasar-agot-adaptation-2026-09-20.md). Обычное содержит восемь: здоровье, плодовитость, компенсацию штрафов к ним, уменьшение стресса, две вероятности наследования неактивных генетических свойств и снижение инбридинга. Добавление опыта в обычное благословение не предусмотрено. Название старшего благословения изменено с «Великое» на «Большое» по последней формулировке пользователя; внутренний идентификатор сохранён.

«Валирийский раб» содержит семь параметров: `fertility = -10000` и по `-100` к дипломатии, военному делу, управлению, интригам, учёности и доблести. Сам модификатор не обнуляет базовые навыки, не назначает владельца, не добавляет свойства и не меняет отношения. Обнуление базы — отдельное утверждённое действие профиля Прислуги в «Оке» и «Трактатах».

Слово `Wife` осталось только в указании источника. Благословения доступны вне зависимости от пола и брака.

## «Обратиться к Валирийским Богам»

Подготовлено взаимодействие `agot_di_rusbar_valyrian_gods_interaction` в [common/character_interactions/agot_di_rusbar_valyrian_gods_interaction.txt](../common/character_interactions/agot_di_rusbar_valyrian_gods_interaction.txt). Доступно игроку в категории DI при включённом меню DI; цель — живой человеческий персонаж, включая самого игрока. Ограничения по вере, культуре, полу, браку и должности не добавлены. ИИ его не использует.

Шесть взаимоисключающих вариантов: выдать каждое из трёх состояний либо снять каждое из них. Скрытие вариантов зависит от состояния получателя, а не от выбранной кнопки:

| Текущее состояние получателя | Доступные варианты |
|---|---|
| Нет ни одного из трёх модификаторов | Выдать Большое благословение, обычное благословение или «Валирийского раба» |
| Есть Большое благословение | Только снять Большое благословение |
| Есть обычное благословение | Только снять обычное благословение |
| Есть «Валирийский раб» | Только снять «Валирийского раба» |
| Несколько модификаторов добавлены извне | Только снять один из имеющихся; выдача закрыта до снятия всех |

За одно обращение выполняется одно действие. Выдача постоянная, без таймера; смена состояния требует сначала снять старое, затем отдельным обращением выдать новое. Если вариант не выбран либо устарел после изменения получателя, отправка запрещена. Перед эффектом повторяются проверки контекста и выбранного действия; каждая ветка выдачи дополнительно запрещает наложение поверх любого из трёх модификаторов.

Взаимодействие только добавляет и удаляет модификаторы. Оно не обнуляет базовые навыки и не добавляет верность. Снятие «Валирийского раба» убирает его штрафы, но не отменяет отдельное обнуление базы, если оно ранее выполнено профилем Прислуги.

Использованы штатные `send_option`, `send_options_exclusive`, `can_send`, `on_accept`, `is_available` из документации установленной игры `game/common/character_interactions/_character_interactions.info`; настройка видимости DI повторяет действующий `DI_misc_variables_story` / `DI_cheat_menu`. Человеческая цель проверяется штатным триггером AGOT `is_human`.

## Иконки и локализация

Иконки размещены в `gfx/interface/icons/modifiers/`, имена DDS совпадают со значениями `icon` в определениях. Формат соответствует установленным штатным иконкам CK3: 60×60, DDS A8R8G8B8, шесть уровней уменьшения (60, 30, 15, 7, 3, 1), по 19 264 байта. PNG уменьшены фильтром Lanczos, прозрачность сохранена. Дополнительное сжатие с потерями не применялось; уменьшения размера достаточно для этих небольших файлов.

Исходные PNG не изменены. `Valyrian_Bless_Low.png` пока не используется.

Названия и описания добавлены в `localization/russian/agot_di_rusbar_blessings_l_russian.yml` и `localization/english/agot_di_rusbar_blessings_l_english.yml`. Описания написаны заново для валирийской тематики; файлы имеют UTF-8 BOM и LF.

## Проверка и состояние

Проверены точность переноса параметров, структура определений, отсутствие дублей полей, имена иконок, чтение DDS с сохранением пикселей и прозрачности, комплектность обеих локализаций. Исходный файл и PNG не изменены переносом.

Условия и ветки эффектов дополнительно проверены интерпретацией разобранных игровых файлов: восемь комбинаций наличия модификаторов, шесть операций и пустой выбор, отключённое меню DI, ИИ, мёртвый/нечеловеческий получатель, устаревший выбор и противоречивые флаги выбора. Всего 820 сочетаний; посторонние модификаторы сохраняются, выдача поверх имеющегося состояния не происходит. Это проверка логики скриптов, а не запуск движка CK3. Обе локализации содержат по 16 согласованных ключей.

Подготовлены три модификатора и взаимодействие выдачи/снятия. Дополнение зарегистрировано отдельным `.mod` в пользовательской папке игры; набор и порядок модов в лаунчере не менялись. В запущенной игре новые файлы не проверены. Состояние всех восьми взаимодействий описано в [отчёте реализации](implementation-2026-09-20.md).
