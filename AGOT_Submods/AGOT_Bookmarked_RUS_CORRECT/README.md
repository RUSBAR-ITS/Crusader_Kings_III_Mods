# AGOT Bookmarked | Исправления русификатора

Корректирующий мод для **AGOT Bookmarked** (Workshop `3149692324`, метаданные версии `1.0`) и **AGOT BOOKMARKED RU** (`3518584623`, версия `1.1`). Подготовлен для CK3 `1.19.0.6` по установленным файлам из [сверки](../../docs/reports/agot-bookmarked-russian-2026-09-18/README.md).

## Что исправлено

Всего изменено **20 русских ключей**:

- Восстановлены два разорванных описания Джоффри: оба абзаца сохранены и соединены через `\n\n`.
- Закрыты четыре тега `#bold` в описаниях Эйгонов для испытаний.
- Исправлены две повреждённые последовательности переноса в описании Века Крови.
- Вместо четырёх `<insert imagination>` написаны полноценные описания Мерна IX Гарденера, Аргилака Дюррандона, Харрена Хоара и Торрхена Старка.
- Исправлены опечатки «Эйегона», «присоеденил», «Гарднеров», несогласованное написание Дейнис и Деймона, лишние пробелы и пунктуация из отчёта.
- Восстановлена шутка про «год, полный ошибок». Приведены в порядок кавычки в описаниях Хариса и Уолдера, добавлена пропущенная точка в описании Аррека, исправлено многоточие в описании Века Крови.

Источники новых текстов и принципы согласования имён: [terminology-and-descriptions.md](docs/terminology-and-descriptions.md). Новые описания написаны для начала Завоевания и не предрешают исход кампании.

## Подключение

Название в лаунчере: **AGOT Bookmarked | Исправления русификатора**.

Разместить после **AGOT BOOKMARKED RU**, который должен идти после **AGOT Bookmarked**. Основной AGOT и его русификатор остаются выше. Мод дополняет русификатор Bookmarked и не заменяет его целиком.

Готовый внешний дескриптор: [AGOT_Bookmarked_RUS_CORRECT.mod](../AGOT_Bookmarked_RUS_CORRECT.mod). В нём указан прямой путь к этой папке репозитория. Для подключения достаточно поместить этот `.mod` в `Документы/Paradox Interactive/Crusader Kings III/mod/`, а затем добавить мод в набор лаунчера.

## Файлы и обновления

Три файла локализации в UTF-8 BOM:

- [zzzz_agot_bookmarked_rus_correct_l_russian.yml](localization/replace/russian/zzzz_agot_bookmarked_rus_correct_l_russian.yml) — 20 исправленных значений для переопределения.
- Полная исправленная копия `localization/russian/agotbm/agotbm_bookmark/agotbm_bookmark_characters_l_russian.yml` — заменяет исходный файл с физически разорванными строками до его чтения игрой. Содержит все 133 исходных ключа.
- Полная исправленная копия `localization/russian/agotbm/agotbm_bookmark/agotbm_bookmark_groups_l_russian.yml` — сохраняет все пять ключей и исправляет описание Века Крови.

Файл названий лагерей и титулов наследуется от русификатора. В итоге доступны все **146 ключей** оригинала. Значения полных копий согласованы с файлом переопределений. `replace_path` не используется; игровых скриптов и изменений механик нет.

[source-manifest.json](docs/source-manifest.json) фиксирует хеши и точные изменения строк. [new-descriptions.json](docs/new-descriptions.json) — исходный текст четырёх новых описаний. Остальные исправления задаются в скрипте сборки. Файл `zzzz_...` и полные копии генерируются сборкой.

После обновления Bookmarked или русификатора требуется повторная сверка: полные копии могут скрыть изменения исходников. Сборка и проверка останавливаются при несовпадении хешей любого из шести проверенных EN/RU-файлов.

Из корня репозитория:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File AGOT_Submods/AGOT_Bookmarked_RUS_CORRECT/tools/Build-AGOTBookmarkedRusCorrect.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File AGOT_Submods/AGOT_Bookmarked_RUS_CORRECT/tools/Test-AGOTBookmarkedRusCorrect.ps1
```

Проверяется полный набор ключей, сохранность обоих абзацев Джоффри и всех незатронутых строк, устранение семи технических дефектов и четырёх заглушек, кодировка, форматирование, подстановки и путь дескриптора. Отображение всех экранов в запущенной игре не проверялось.
