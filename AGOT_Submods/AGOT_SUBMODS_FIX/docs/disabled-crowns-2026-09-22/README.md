# Crowns of Westeros исключён из общего фикса

22 сентября 2026 года пользователь решил отключить Crowns of Westeros и поручил менять только наш фикс. Профиль игры, набор модов и Workshop не редактировались.

## Сохранённые файлы

В `runtime/` находятся побайтные копии восьми прежних файлов. Каталог расположен внутри документации, вне загружаемых CK3 каталогов `common`, `events`, `gfx` и `localization`.

| Прежний игровой путь | Назначение |
|---|---|
| `common/modifiers/ntc_artifact_modifiers.txt` | Характеристики корон Crowns |
| `common/on_action/ntc_artifacts_startdate.txt` | Стартовая раздача артефактов и признак присутствия Crowns |
| `common/artifacts/templates/ntc_artifacts_templates.txt` | Шаблоны артефактов |
| `common/scripted_effects/00_ntc_scripted_effects_crowns.txt` | Создание корон, включая исправленные записи Гарденеров |
| `common/scripted_triggers/00_ntc_crown_commission_triggers.txt` | Условия заказа корон |
| `events/activities/agot_coronation_activity/agot_coronation_crown_commission_events.txt` | Копия событий AGOT с добавлениями Crowns |
| `events/activities/agot_coronation_activity/agot_activity_events_crown_commission.txt` | Заглушка старого пути событий Crowns |
| `events/ntc_find_lost_crown_events.txt` | Поиск короны Роланда |

Удаление обеих копий событий заказа существенно: текущий общий фикс больше не подменяет штатный файл AGOT расширенной версией Crowns. Он также не содержит заглушек, которые отключали бы базовую коронацию.

[manifest.json](manifest.json) сохраняет контрольные суммы, прежние назначения файлов и восемь исключённых записей источников. Фрагменты сборщика и прежних проверок сохранены в `build-fragment.py.txt` и `test-fragment.py.txt`; текущие инструменты их не импортируют и не выполняют. Простое повторное выполнение `Build.py` не включает Crowns.

## Что сохранено

Все остальные **79** игровых файлов совпадают с состоянием до изменения. В частности, `usf_crowns_without_creator_effects.txt` остаётся активным: это пять функций **основного AGOT**, используемых **Legacy of the Dragon**, а не определения Crowns of Westeros. Сохранены исправления COW, Valyrian Steel, DI AGOT, Core, Bookmarked и локализации.

Из внутреннего и внешнего дескрипторов в репозитории удалена только зависимость `AGOT - Crowns of Westeros`. Копии дескрипторов в профиле игры не изменялись. Исторический шаблон дескриптора сохранён, а генератор исключает эту зависимость при построении текущих дескрипторов.

## Проверка

- `Build.py --check`: совпадают закреплённые источники и все 79 выходных файлов.
- `Test.py`: 227 проверок, включая отсутствие восьми файлов в загрузке, сохранность архива и функций корон Legacy.
- `TestResources.py`: 364 проверки; эффективные пути теперь проверяются по текущему списку модов, прочитанному без изменений. Требование полного совпадения списка с историческим аудитом 20 сентября заменено проверкой фактического поставщика каждого исправленного ресурса.
- [application-validation.json](application-validation.json): подтверждены неизменность 79 оставшихся файлов, исходников, `dlc_load.json` и зарегистрированных `.mod`. База `launcher-v2.sqlite` изменилась во время работы внешним процессом; наши команды её только читали для расчёта суммы. Побайтная неизменность всей базы лаунчера не заявляется, настройки из неё не переписывались.

Игра не запускалась. Сохранённые кампании и уже существующие в них артефакты не обрабатывались. Для возвращения Crowns в фикс нужно явно восстановить соответствующую часть сборки, источники и файлы из архива; один выбор мода в лаунчере не меняет состав нашего фикса.
